# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report via:

- **GitHub**: Use [GitHub's private vulnerability reporting](https://github.com/Scetrov/scetrov.live/security/advisories/new)
- **Email**: Contact the repository owner through their GitHub profile

## What to Include

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (if applicable)

## Disclosure Expectations

- Vulnerabilities will be acknowledged within **7 days** of receipt
- A fix timeline will be communicated based on severity
- Credit will be given to reporters (unless anonymity is requested)

## Scope

This is a personal brochure site (static HTML/CSS/JS served via Go). The attack
surface is limited to the served static assets and the Go file server.
